# mathlib-fp 2.7.0 release notes

### Added

- Added real-double Bernoulli logistic and Poisson generalized linear models
  with canonical links, scaled pivoted-QR IRLS, deviance backtracking, and
  explicit convergence, separation, boundary, rank and conditioning results.
- Added final-information standard errors, fitted means, response/deviance
  residuals, null deviance, Pearson diagnostics, and validated prediction.
- Added independent 90-digit reference fixtures, analytic/adversarial tests,
  a complete GLM example, model-selection guidance and current API evidence.

### Documentation

- Updated the capability inventory, statistics and task guides, support and
  security policy, versioned API/docs, package metadata and release roadmap.
