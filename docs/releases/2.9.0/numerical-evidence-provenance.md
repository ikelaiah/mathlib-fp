# v2.9.0 numerical and performance provenance

The [numerical catalogue](numerical-evidence.json) carries forward the
qualified v2.8.0 records and adds `bounded_global_optimization`.
The implementation is original Object Pascal under MIT, following
[Storn and Price (1997)](https://doi.org/10.1023/A:1008202821328), with normalized
finite-box coordinates, deferred population updates and bounded coordinate
polishing. There is no copied third-party code or external runtime.

Independent references are the analytic minima in the SFU test-problem
library: [Rastrigin](https://www.sfu.ca/~ssurjano/rastr.html),
[Rosenbrock](https://www.sfu.ca/~ssurjano/rosen.html),
[Ackley](https://www.sfu.ca/~ssurjano/ackley.html), and
[Sphere](https://www.sfu.ca/~ssurjano/spheref.html). Tests implement these
equations independently from the optimizer and compare against their known
minima, with exact quadratic and linear boundary identities as additional
oracles. No fixture is generated by the production optimizer.

The [tests](../../../tests/TestGlobalOptimization.pas) also check partial call
budgets, deterministic state/replay, global RNG isolation, nonfinite recovery,
validation, fixed/extreme bounds, callback mutation and exceptions, and
separate local-polish diagnostics. These corpus budgets are not worst-case
guarantees or global-optimality certificates.

The [performance contract](performance-evidence.json) carries forward v2.8.0's
unchanged benchmark rows. No new optimizer speedup claim is made.
