# Numerical-evidence catalogue provenance

The [2.5.1 catalogue](numerical-evidence.json) carries forward the stable
family records from the [2.5.0 catalogue](../2.5.0/numerical-evidence.json).
Version 2.5.1 changes no Pascal source, numerical behavior, tests, or public
API, so those records and their source references remain applicable.

Only the catalogue's top-level `release` and `inventory_release` fields advance
to `2.5.1`, matching the unchanged capability inventory now identified as the
current documentation release. The individual family records, budgets, test
references, edge cases, and fault-injection details are unchanged.
