# Performance-manifest provenance

The [2.5.1 performance manifest](performance-evidence.json) carries forward
the benchmark contracts and prior measurements from the
[2.5.0 manifest](../2.5.0/performance-evidence.json). Only the top-level
release identifier changes. The benchmark definitions, hard resource limits,
and prior baseline values are unchanged.

Version 2.5.1 changes no numerical implementation, so it makes no new
performance claim. Its release qualification runs the carried-forward
benchmarks against the clean source archive; the measured v2.5.0 timing report
remains the [2.5.0 performance report](../2.5.0/performance-evidence.md).
