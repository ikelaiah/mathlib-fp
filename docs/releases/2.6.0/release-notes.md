# mathlib-fp 2.6.0 release notes

### Added

- Added stable Butterworth and Chebyshev Type I SOS IIR design for low-pass,
  high-pass, band-pass, and band-stop responses, with complex frequency
  response and pole-stability diagnostics.
- Added a snapshot-owning streaming SOS filter with explicit state save and
  restore, atomic block processing, and a deterministic multi-block example.
- Added independent high-precision coefficient and response fixtures,
  numerical evidence, and updated API, task, and applied-numerics guidance.
