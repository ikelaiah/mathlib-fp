# Spectral fixture provenance

The committed values in [`../../../tests/SpectralPlanFixtures.inc`](../../../tests/SpectralPlanFixtures.inc)
are generated by [`../../../tools/generate_spectral_plan_fixtures.py`](../../../tools/generate_spectral_plan_fixtures.py)
with CPython 3.13.5's standard-library `decimal` module at 90-digit context
precision. The generator evaluates sine and cosine with a Decimal Taylor series
and computes DFT sums directly; the Pascal implementation is not used to make
the expected values. It uses no network resources or third-party numerical
packages.

The seven-point complex FFT fixture uses the explicit rational-valued inputs in
the generator and the unscaled forward DFT convention. Its committed real and
imaginary bins are rounded to 55 digits after the decimal point.

The STFT fixture uses five real samples `(1, -0.5, 0.25, 1.5, -1.25)`, frame
length 4, hop 2, and a rectangular window with samples `(1, 1, 1, 1)`. It uses
left padding 3, five frames, padded length 12, and right padding 4. The
generator directly evaluates each unscaled four-point frame DFT, then applies
the conjugate-bin edit `X[2,1] += 0.25 + 0.125i` and
`X[2,3] += 0.25 - 0.125i`. Its synthesis reference independently evaluates
the normalized inverse DFT for every frame, overlap-adds with the same window,
divides by the explicit sum-of-squared-window denominator at each retained
sample, and trims the three leading padded samples. Expected components are
rounded to 55 digits. Focused tests compare both the complete STFT matrix and
the edited reconstruction to these committed values.

Regenerate with `python tools/generate_spectral_plan_fixtures.py`; the normal
test suite consumes only the committed include and does not need Python.
